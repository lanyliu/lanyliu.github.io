# 職涯區塊已涵蓋紀錄

這個檔案讓早報記得「AI 職涯階梯」和「資料分析師 / 資料科學家職涯」這兩個區塊
前幾天講過什麼，避免每天端出同一批常青文章換句話說。

早報每天寫完頁面後會自己往這裡追加一筆，並把檔案裁到最近 30 筆。
你不需要手動維護。想讓某個主題重新可用，把對應那行刪掉就好。

格式（最新的在最上面）：

```
## YYYY-MM-DD
- 階梯｜具體角度｜來源網域
- 資料｜具體角度｜來源網域
```

「具體角度」寫實際講了什麼，不是區塊名稱。
例如「Staff 與 Principal 的職責分界」而不是「職涯階梯」。
