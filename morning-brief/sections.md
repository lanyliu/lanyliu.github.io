# 早報區塊設定

這個檔案決定早報下半部有哪些主題區塊、順序、以及各自的規則。
想加減區塊、換順序、調整範圍，改這裡就好，不用動排程任務。

排程任務每天執行時會先讀這個檔案。

## 使用方式

- **啟用**填 `是` 或 `否`。填 `否` 就跳過，不用刪掉整段。
- **順序**照這個檔案由上而下排列。想換順序直接搬動整段。
- **取幾則**是這個區塊最多放幾則。
- **地域**限制搜尋範圍。填 `全球` 就不限。
- **防重複**填 `是` 的區塊，會套用 covered-topics.md 的三道關卡
  （角度 14 天內不重複、來源網域 7 天內不重複、要有時間錨點）。
  常青主題填 `是`，每天本來就會變的新聞類填 `否`。
- **範圍**寫給 Claude 看的內容界定，愈具體愈好。

追蹤來源（sources.md）的區塊插在哪，由 sources.md 自己的「呈現方式」決定。

## 1. 遠端 / 接案機會

- 啟用：是
- 取幾則：2–3
- 地域：優先台灣 / 大中華 / APAC，或全球遠端
- 防重複：否
- 範圍：AI 與資料領域的遠端、接案、外包、合約機會。涵蓋資料分析師、
  資料科學家、ML/AI 工程。平台動態、當前職缺與趨勢、行情與費率訊號。

這個區塊有最高優先權。有具體且有時效的機會出現時，除了放在這裡，
也可以在「需要你處理」佔一行。

## 2. 每日 AI 大事

- 啟用：是
- 取幾則：2–4
- 地域：全球
- 防重複：否
- 範圍：當天最重要的 AI 進展。重大模型發布、大公司與實驗室公告、
  募資、政策法規。取當天或過去 24–48 小時內的內容。
  每則一行，來源片語做成連結。保持中性陳述，不評論。

## 3. AI 職涯階梯

- 啟用：是
- 取幾則：1–2
- 地域：全球
- 防重複：是
- 範圍：AI/ML 工作的角色與層級演進。IC 軌與管理軌的差異、各層級的
  分野、Applied ML / LLM / MLOps 這類 AI 專屬職稱如何對應到一般
  工程職級。今年職級制度正在怎麼變。

## 4. 資料分析師 / 資料科學家職涯

- 啟用：是
- 取幾則：1–2
- 地域：台灣、大中華區
- 防重複：是
- 範圍：這兩個角色的工作內容、彼此差異、技能與進階路徑、市場與前景
  訊號。職缺與薪資數據聚焦台灣和大中華區，優先 104 等在地來源。
